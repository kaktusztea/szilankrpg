## Csapdák (a legértékesebb rész — mind CSENDBEN hibázik)

1. **Hash-alapú cache és a modulbontás.** A `compute_sources_hash` a YAML-ok mellé a
   *generátor kód* tartalmát is hasheli. A bontás után ez 1 fájl helyett 10 — ha csak a
   `generate_tables.py`-t hashelnéd, egy `gen/fortelyok.py` módosítás **nem invalidálná**
   a cache-t, és csendben elavult táblákkal fejlesztenél. (`gen/cache.py::_generator_files`)
2. **A Vite freshness ellenőrzés ugyanez.** A `tablesAreFresh` csak a YAML-ok mtime-ját
   nézte; most a `generate_tables.py` + `gen/*.py` mtime-ja is beleszámít.
3. **Dev middleware + query string = HTTP 200 hamis JSON.** A cache-busting `?v=`
   bevezetése után a vite data-middleware nem találta a fájlt, és **200-as státusszal az
   SPA fallback HTML-t** adta vissza. A status kód elrejtette, csak a válasz **mérete**
   (984 vs 14850 bájt) mutatta meg. Tanulság: statikus fájl végpontnál a status kód
   önmagában semmit nem bizonyít — méretet/tartalmat is nézz.
4. **Verzió-ellenőrzés a mount ELŐTT.** Ha mountolás után töltenénk újra, az URL-es
   karakter import kétszer futna le → **két slot**. Ezért `main.tsx`-ben blokkolva
   (1s timeout), nem effektben.
5. **Blokk-kinyerő script átvitte a modul-szintű kódot.** A `generate_tables.py` bontásánál
   a „def-től a következő def-ig" vágás a `hu_sort_key` blokkjához csapta a *modul-szintű
   útvonal konstansokat* is (`DATA_DIR = SCRIPT_DIR`), ami felülírta a helyes útvonalakat →
   `data/gen/sources/...` lett a source dir. Az egyetlen ok, amiért kiderült: **a generált
   JSON-okat bit-azonosságra ellenőriztem** (`git status data/tables/` → csak a
   `.sources_hash` változhat). Ezt a check-et MINDIG csináld meg generátor-refaktornál.
6. **`[key: string]: any` catch-all a data-típusban.** Elrejtette 18 valódi kulcsot és egy
   elavult mezőt. Ha ilyet találsz, a törlése után a fordítási hibák **maguk a leletek** —
   ne `as any`-vel foltozd őket, hanem `Pick<>`-kel vagy a valódi típussal.
7. **Halott kód detektálásnál a „csak a saját fájlban használt export" NEM halott kód.**
   Külön kell kezelni: (a) valóban használatlan → törlés, (b) csak belső → `export` levétele.
   A séma/adatmodell típusoknál a (b) sem érdemes.
8. **`evaluate` a feloldatlan szabályokat csendben kihagyja** (nem dob). Ezért biztonságos
   szűrt szabálylistával hívni (`data.rules.filter(...)`), de ezért is maradhat évekig
   észrevétlen egy olyan szabály, amelynek egy inputja sosem kerül a kontextusba.

## Újrahasznosítható detektálók

Halott export vs csak-belső export (a projekt gyökeréből, `web/karakter/src`-ben):
```bash
for f in $(find . -name "*.ts" -o -name "*.tsx" | grep -v test); do
  grep -oP '^export (?:async )?(?:function|const|class) \K\w+|^export (?:interface|type) \K\w+' "$f" | while read sym; do
    ext=$(grep -rlw "$sym" --include="*.ts" --include="*.tsx" . | grep -v "^$f$" | wc -l)
    infile=$(grep -cw "$sym" "$f")
    if [ "$ext" -eq 0 ]; then
      [ "$infile" -le 1 ] && echo "TRULY-UNUSED: $sym ($f)" || echo "EXPORT-ONLY: $sym ($f)"
    fi
  done
done | sort
```

Data-típus ↔ yaml drift (a catch-all elrejti, ezért érdemes külön mérni) — **kipróbált**:
```python
import re, yaml
y = yaml.safe_load(open('data/sources/konstansok.yaml'))
src = open('web/karakter/src/engine/data-types.ts').read()
blk = src[src.index('export interface KonstansokRaw'):]
blk = blk[:blk.index('\n}\n')]
# CSAK a 2 szóközzel indentált (top-level) mezők — a nested objektumok mezői nem számítanak
decl = set(re.findall(r'^  ([A-Za-zá-űÁ-Ű_][\w_á-űÁ-Ű]*)\??:', blk, re.M))
print('yaml-ban van, típusban nincs:', sorted(set(y) - decl))
print('típusban van, yaml-ban nincs:', sorted(decl - set(y)))
```

## Konvenciók, amiket ez a refaktor rögzített

- **Egy adatterület = egy generátor modul** (`data/gen/{terület}.py`); a
  `generate_tables.py` csak CLI + sorrend.
- **Séma kötelezőség a megjegyzésből**: `# opcionális`, `# generált` (lásd `gen/schema.py`).
- **Konstansok típusa**: nincs catch-all; szeletekhez `Pick<KonstansokRaw, ...>`.
- **Limit/kalkuláció a `rules.json`-ba tartozik**, a TS csak kiértékel (`kepzettseg-limit.ts`
  a minta). Ha a szabály hardcode-ol egy számot, előbb a szabályt javítsd konstansra.
- **Formázó egy helyen**: `fmtHatás` (hatás → szöveg), `előnyHátrányLabel` (E/H címke),
  `hatásBadgeLabel` (dobás-hatás badge).
- **Teszt a kiemelt tiszta logikára**, és ahol a *bekötés* a lényeg, a teszt a VALÓDI
  `rules.json` / `konstansok.json`-t töltse be (`__tests__/load-gamedata.ts`).
- Közös teszt segédek: `__tests__/localstorage-stub.ts`, `__tests__/karakter-fixture.ts`.

## Ugyanaznap, külön téma: böngésző cache (nem refaktor, de ide tartozó tanulság)

Panasz: megosztott karakter URL újranyitásakor régi app fut. Ok: a GitHub Pages
`max-age=600`-at ad az `index.html`-re, headert nem lehet állítani → cache-elt HTML a régi
hash-elt bundle-re hivatkozik. Két védelem: (1) minden runtime JSON kérés `?v={APP_VERSION}`,
(2) indulási verzió-ellenőrzés `metadata.json`-ból (`cache: 'no-store'`) → egyszeri,
cache-kerülő újratöltés a `#hash` megőrzésével, sessionStorage loop-védelemmel.
Részletek: `engine_spec.md §30.5`, `engine/version-check.ts`.
**Korlát, amit tudni kell**: az ellenőrzés kódja az ÚJ bundle-ben van, tehát egy már
elavult HTML-t futtató klienst nem gyógyít meg — ott egyszeri hard refresh kell.
Service workert szándékosan NEM vezettünk be (rosszul megírva súlyosbítja).
