## Csapdák

1. **Prefix-ütközés a csere-táblában:** `fegyvergenerator_balansz_elemzes` a `fegyvergenerator_balansz` prefixét
   tartalmazza - a hosszabbat ELŐBB kell cserélni (és a modulnév-cserét szóhatárral), különben
   `modell_elemzes.py` lesz belőle.
2. **Mélységváltás:** `code/balance/` → `code/fegyvergenerator/` azonos mélység, így a `parent.parent.parent`
   repó-gyökér útvonalak változatlanul jók. A `code/sync_fegyvertablazatok.py` viszont egy szinttel MÉLYEBBRE került:
   `parent.parent` → `parents[2]`, és a `/ "balance"` sys.path-ra már nincs szükség (egy könyvtárban vannak).
3. **`git stash` + `git mv` együtt:** a stash/pop a staged rename-eket `D` (unstaged törlés) + `A` párokra bontja.
   Javítás: `git rm --cached <régi útvonalak>` → a git újra rename-ként párosítja. (Tanulság: átnevezés közben
   ne stash-elj ellenőrzéshez - inkább `git show HEAD:<régi>` a régi verzió futtatásához.)
4. **Transzformáló script futtatása a `git mv` ELŐTT/KÖZBEN:** egy, a mozgatás előtt indult `os.walk` a régi
   helyre visszaírt egy fájl-másolatot (`code/balance/fegyverek_regi_uj_osszehasonlitas.py`, nem követett).
   Előbb `git mv`, UTÁNA a hivatkozás-csere; a végén `git status` + "nincs maradék régi útvonal" grep.
