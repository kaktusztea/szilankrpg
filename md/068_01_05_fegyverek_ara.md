# Fegyverek ára

A fegyverek ára - a péncélokhoz hasonlóan - egy arány-szorzó, ami egymáshoz képest mutatja meg az egyes típusok értékét. Jó tudni, hogy a fegyverek jellemzően olcsóbbak a [Páncéloknál](069_06_pancel_ara.md).

```
10 átlagos hosszúkard == 1 bőrvért ára
(átlagos, acél)          (átlagos)
```

## Fegyver ár számítása

```
Fegyver ár szorzója =

x Hossz
x Alapanyag
x Idea
```

### ⚜️ Hossz szorzó

```
0.5x - 1-2 hossz
  1x - 3-6 hossz
  2x - 7+  hossz
```

### ⚜️ Alapanyag szorzó

Azonos a Páncélok Alapanyag szorzóival.

```
  0.1x : Fa
  0.5x : Bronz
    1x: Acél
   10x: Abbitacél
  100x: Mithrill
   ∞  : Lunír
```

### ⚜️ Idea szorzó

Azonos a Páncélok Idea szorzóival.

```
 -5        0.05x
 -4        0.1x
 -3        0.15x
 -2        0.25x
 -1        0.5x
  0        1x
 +1        2x
 +2        4x
 +3        7x
 +4       10x
 +5       13x
```

## Példa: átlagos Hosszú kard

```
1x: Kard, hosszú

1x: hossz(3)
1x: acél
1x: Idea(0)
```
