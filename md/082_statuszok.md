## Státuszok ✴️

A **Státuszok** ideiglenes, vagy tartós hatások a karakteren, amikből "ki kell gyógyulnia".

A Státuszt az "kapja", akin a kondíció tartósabb, vagy aki a cselekvő fél (pl. aki támad, akinek levágták a karját).

Megszüntetésük: a kiváltó ok és a szituáció ismerete alapján a KM dönt.

Ugyanabból a Státuszból egyszerre egy fok lehet aktív, súlyosbodáskor a magasabb fok lép érvénybe.\
Kivétel: Érzékvesztés (érzékenként).

### ✴️ Hangulat (1) Fogékony

A nem-mágikus érzékszervi, vagy érzelmi ingerek fokozottabban hatnak rád. Érzelmileg jobban megnyílsz - pozitív és negatív értelemben is.

A KM adhat valamire `Előny+1`, vagy `Hátrány-1` módosítót - hogy mire, az szituációfüggő.

### ✴️ Hangulat (2) Inspirált

Inspirál egy műalkotás, egy táj, egy beszélgetés. Ez kreatív energiákat szabadíthat fel, de akár a figyelmed is elvonhatja a fontos dolgokról.

```
Előny+1
  kreatív tevékenységekre

Hátrány-1
  koncentrációt igénylő feladatokra
```

### ✴️ Hangulat (3) Eufórikus

Eufórikus állapotban vagy, talán valamilyen sikerélmény vagy varázslat hatására. Ilyenkor túlzottan magabiztos vagy, meggondolatlan döntéseket hozhatsz.

```
Előny+1
  Kreatív tevékenységekre

Hátrány-1
  Ellenséges varázstudó:
    Asztrálmágia Komplexitás-próbájára
    (asztrális befolyásolásnak jobban
     ellenáll az eufórikus személy)

Hátrány-2
  Koncentrációt igénylő feladatokra
```

### ✴️ Hangulat (4) Obszesszív

Megszállottá válsz egy dolog vagy személy iránt. Ez motivációt adhat, de a megszállottság elvakíthat és rossz döntésekhez vezethet.

```
Automatikus kudarc
  KM mondja meg, mit
  követeljen a játékoson

Előny+1
  Mindenre, ami az obszesszió
  tárgyához kötődik
  (nem harci/misztikus dobásokra)

Hátrány-1
  Minden más Képzettségpróbára
```

### ✴️ Zavar (3) Sokk

Nagyjából `10-20` percig tart, KM dönt. Az aktuális harci jelenetben nem képes részt venni.

```
Automatikus kudarc
  KÉ dobás
  Tulajdonságpróbákra
  Képzettségpróbákra

Harcképtelenség
Mozgás - lecövekelt

Pszí használat elvesztése
Varázslás képesség elvesztése

Beszéd (zavart, vagy némult)
  (szituációfüggő)
```

#### Kijövetel sokkból automatikusan

```
(20 - Önuralom) perc után
  enyhül 2.fokra
```

```
Képzettségpróba:
  Emberismeret + Érzékenység

Célszám: 12 (Nehéz)
  → siker enyhíti 2.fokra
```

```
Mágiával kihozni
(1, 2, 3 szintet enyhíthet)
```
